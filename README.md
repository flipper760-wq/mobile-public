# Mobile weather page deployment

This folder is ready for static hosting.

- `index.html` is a copy of `../mobile.html`.
- Upload this folder to GitHub Pages, Netlify, Cloudflare Pages, or another static hosting service.
- The page does not need a backend server. It fetches weather data directly from FMI, Yr/MET Norway, and Open-Meteo.
- After publishing, open the HTTPS address on a phone and add it to the home screen.

When `../mobile.html` is changed later, copy it again over this folder's `index.html` before publishing.
